Number Field
Numeric input for values like quantity, count, or ID. Same geometry as the Input Field — label 12px/500 var(--ink-600), value 12px/500 var(--ink-900), height 40px (--field-h), border 1px var(--line-200), focus 1px var(--ink-600), 4px radius. Native browser spinners are suppressed in favour of the stepper variant below. On hover the field background fills var(--surface-50).
GB
Value must be between 0 and 100
Number Spinner
Stepper for bounded numeric input — decrement on the left, increment on the right, centred value. Buttons fill #F4F4F4 (surface-100) with a 1px var(--line-200) divider; a step button greys out (surface-50 / ink-400) once the value reaches its bound. Height is the locked 40px form-field height (--field-h); the small variant is narrower only.

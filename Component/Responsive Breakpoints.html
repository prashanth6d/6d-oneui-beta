Responsive Breakpoints

The 6D-OneUI breakpoint system. Enterprise, desktop-first screens are designed at 1440px on a 12-column grid; tablet uses 6 columns and mobile uses 2 columns. Root font size is 16px, so rem maps directly to the pixel values below. Do not create custom breakpoints unless approved.

Regular Popup
Reset Password
A new system-generated password will be created and sent to the user's registered email address.
What happens next:
  1. The system will generate a new temporary password automatically.
  2. The user will receive an email with their new password and login instructions.
  3. The user will be asked to change this temporary password after logging in.
  4. This action will be recorded in the audit trail for security and compliance.
Error Popup (variant)
Unable to Reset Password
We couldn't generate a temporary password for this user at the moment. Please verify the user details and try again.
What happens next:
  1. Verify the user's email address and account status.
  2. Try the password reset action again after a few moments.
  3. If the issue continues, contact the system administrator or support team.
  4. This failed attempt will be recorded in the audit trail for security purposes.
